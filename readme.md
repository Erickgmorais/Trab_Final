# Portal sobre filmes e series de Halloween 

Este projeto foi desenvolvido como parte das atividades da UC10, com o objetivo de aplicar os conhecimentos adquiridos durante o curso no desenvolvimento de páginas web.

O projeto utiliza tecnologias de desenvolvimento web para estruturar e apresentar o conteúdo de forma organizada, buscando proporcionar uma navegação simples e intuitiva para os usuários.

🚀 Tecnologias Utilizadas

HTML5: estruturação do conteúdo da página.


▶️ Como Executar o Projeto

Faça o download ou clone este repositório.

Abra a pasta do projeto no Visual Studio Code ou em outro editor de código.

Localize o arquivo index.html.

Abra o arquivo no navegador para visualizar a página.


🎯 Objetivos de Aprendizagem

Organizar arquivos e recursos de um projeto.

Utilizar o Git e o GitHub para versionamento e compartilhamento do código.

Desenvolver boas práticas de documentação de projetos.
